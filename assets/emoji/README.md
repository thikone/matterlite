# Emoji images

Google's Noto Emoji from the `emoji-datasource-google` 6.1.1 npm package (`img/google/64/`),
scaled to 32 px; Apache License 2.0 (`LICENSE-APACHE` at the repository root). One file per
emoji, named by its unified code points (`1f44d.png`). Regenerate with
`crates/mm_emoji/examples/generate.rs`. See `PROVENANCE.md`.
