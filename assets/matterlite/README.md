# MatterLite assets

Assets made for MatterLite (AGPL-3.0-only, like the rest of the project); everything under
`assets/bundled/` and `assets/async/` comes from Warp (see `PROVENANCE.md`).

- `svg/lock.svg`, `svg/archive.svg`: private and archived channel icons, drawn in the style of
  Warp's 24-px icons. Icons are filled white (the renderer tints by the fill, so black draws
  nothing).
- `svg/face-smile.svg`: the React button of the post toolbar (Warp has no emoji icon).
