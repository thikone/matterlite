# M0 progress

M0 (MatterLite.md §18): new repo, Tier A framework crates imported in dependency order and
compiling, WarpUI window on Win/Linux/macOS, CI; `ml_themes`; `ml_workspace` shell with
placeholder panes and `SearchBarView`; read-only spike of `ml_file_views`.

## Done

- [x] Repository bootstrap: workspace, toolchain 1.98.1, rustfmt/clippy/deny config, licenses,
      AGENTS.md, PROVENANCE.md, `script/provenance`, `script/provenance-header`, presubmit CI
- [x] Tier A framework crates, all compiling with their tests passing on Windows:
  - warp_errors (Sentry and websocket hooks removed)
  - string-offset, sum_tree, markdown_parser, settings_value(+_derive), command
  - warp_util (Tier C: pruned to path/file helpers)
  - warpui_core (TUI front-end removed), warpui (wasm platform removed), virtual_fs
  - asset_cache, asset_macro (assets resolved from the repository `assets/`)
  - warpui_extras (file and TOML preference stores, secure storage)
  - warp_features (complete Warp flag list, see pruning backlog), settings
  - warp_core (Tier B: ui, platform, safe_log, async, features; `paths` rewritten for §9)
  - ui_components (gallery example runs: `cargo run -p ui_components --example library`)
  - vim, ipynb_parser, warp_editor, languages, syntax_tree
  - watcher, warp_files (local files only), fuzzy_match
- [x] Assets: Roboto, Hack, password font, 341 icon SVGs, built-in theme backgrounds
- [x] ml_themes: Warp's 21 built-in themes, ThemeSettings in `settings.toml`
      (`[appearance.themes] theme = "dracula"`, snake_case values), AppearanceManager
      (settings changes, OS light/dark, transient preview)
- [x] ml_logging: `<state>/logs/matterlite.log`, rotated per launch and by size
- [x] ml_workspace shell: tab bar (Ctrl/Cmd+T/W, Ctrl+Tab, Ctrl/Cmd+1..9), tool panel with
      the six-tab toolbelt (Alt+1..6 show/hide), right panel (Esc closes), resizable panels,
      placeholder content
- [x] `matterlite` binary: feature flags, settings stores, Appearance, logging, Workspace window;
      portable mode when `data/` exists next to the executable
- [x] ml_editor: Warp's `EditorView` extracted from `app/src/editor` into one file,
      `EditorView.rs` (`EditorView::single_line` and multi-line `EditorView::new`; CRDT buffer,
      undo, selections, soft wrap, IME). Vim, voice, AI context, image attachments,
      autosuggestions, command x-ray and shared-session peers removed. Emacs-style ctrl
      bindings are macOS-only. `ml_editor::init` registers the bindings and the
      `EditorSettings` / `SelectionSettings` groups; the binary calls it at startup.

- [x] SearchBarView (`ml_workspace::search_bar`, from Warp's session history): bordered field
      on `EditorView::single_line`, Clear, Regex and Case toggles, per-pane toggle groups
      (optionally keeping one toggle on), `Matcher`. Used by the History, Files and Search
      placeholder panes; Alt+4…6 focus the field, Esc clears and then returns the focus.
- [x] Theme chooser (`ml_themes::theme_chooser`, from Warp's): searchable list of chat-style
      previews in a panel left of the tool panel; Up/Down apply and save at once, Esc/Enter close;
      light/dark mode aware. Opened with the brush button in the tool panel header or
      Ctrl+Alt+Shift+T (Cmd+Ctrl+T on macOS). Custom YAML themes from `<config>/themes` load
      at startup and with the chooser's reload button.
- [x] ml_file_views read-only spike (`cargo run -p ml_file_views --example file_viewer`):
      `FileView` on `warp_editor` shows rendered Markdown (with a Raw toggle) and Jupyter
      notebooks, highlighted code and plain text, with selection, copy and scrolling. Result
      and the M5 gap list in [FileViews.md](FileViews.md): build thin views on `warp_editor`
      instead of extracting Warp's 31k-line viewers.
- [x] Settings hot reload (`matterlite::config_watcher`): the config directory is watched;
      edits to `settings.toml` apply while running (a file that doesn't parse keeps the current
      settings, an invalid value keeps that setting's current value, a removed setting returns
      to its default), and changes in `themes/` reload the custom themes. Preference errors now
      show their cause (e.g. the TOML line and column).

## Pruning backlog

- warp_features: cut the enum down to the flags MatterLite code references
  (`warp_core::features::MATTERLITE_FLAGS` lists the ones turned on).
- settings: cloud-sync machinery (`SyncToCloud`, `RespectUserSyncSetting`) unused by MatterLite.
- warpui_core: `integration_tests`, `schema_gen`, `settings_value`, `traces`,
  `log_named_telemetry_events`, `defer_scene_build` features; `app_focus_telemetry`,
  `telemetry`; leftover TUI wording in doc comments; single-variant `StoredView`;
  `ShellFamily` use in clipboard_utils (terminal paste escaping).
- warpui: remaining `cfg(target_family = "wasm")` branches; `is_mobile_device`;
  `integration_tests` feature.
- warp_core::ui::icons: the Icon enum still lists every Warp icon (and assets/bundled/svg
  holds the 341 it references).

## Known issues

- The `warpui` Windows clipboard tests use the real system clipboard. They now hold a lock so
  they don't run in parallel (in parallel they crashed the test process with
  STATUS_HEAP_CORRUPTION), but another process using the clipboard during the run can still
  make `test_clipboard_round_trip` fail.
- Tabs stretch wider than `TAB_MAX_WIDTH` when there are few of them.
